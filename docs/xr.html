Graphics

The trainer is also a small real-time graphics project.

One BRDF, four renderers

The lobe is drawn from the same Lambert + GGX formula as the fit (fit.py), the browser renderer (render-gl.js) and the numpy renderer. A test compares this page's JavaScript with the Python.

Lines that survive a headset

One-pixel lines vanish on a see-through display. Every arc and ray is two crossed ribbons of real width in millimetres, drawn as triangles with premultiplied alpha.

Stereo without an engine

Plain WebGL: one draw per eye with the headset's own view and projection matrices. No engine or library to install, about 300 lines.

Limits

  • Not yet run on any headset. Everything on this page was checked in a desktop browser only.
  • The overlay is not hidden by the real machine: virtual lines draw over real parts that should cover them.
  • Two-point alignment fixes position and heading; it assumes the bench is level.
  • The lobe is the fitted model, not measured data, and is drawn on a square-root scale.
  • The comparison table is a protocol. No result exists yet.
